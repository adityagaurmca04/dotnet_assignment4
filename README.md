## 🚀 How to Run

Navigate to the project root directory and run any project using the .NET CLI:

```bash
# Run any program (e.g., Prog1 through Prog10)
dotnet run --project Prog1
dotnet run --project Prog2
dotnet run --project Prog3
dotnet run --project Prog4
dotnet run --project Prog5
dotnet run --project Prog6
dotnet run --project Prog7
dotnet run --project Prog8
dotnet run --project Prog9
dotnet run --project Prog10
```

Alternatively, navigate directly into a specific project folder:

```bash
cd Prog10
dotnet run
```
